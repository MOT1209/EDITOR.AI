# محرّك الرندر متعدد المسارات (المرحلة 3)

> **مبدأ:** التحرير ≠ الرندر. العمليات في `lib/engine/timeline.ts` تعدّل `ProjectState` فقط؛ الرندر يمرّ بطبقتين نقيتين
> قابلتين للاختبار بلا ffmpeg، ثم مُشغّل واحد.

```
ProjectState ──buildRenderPlan──▶ RenderPlan ──compileRenderPlan──▶ وسائط ffmpeg ──runExport──▶ ملف
 (timeline.ts)   (render-plan.ts)  (بيانات متحقَّقة)  (render-compile.ts)       (ffmpeg-export.ts)
```

## لماذا مركِّب جديد (إثبات الضرورة)
المسار القديم يلصق مقاطع **مصدر واحد** تتابعاً. الاختبارات التوصيفية (`tests/audit/known-gaps.test.ts` قبل التعديل) أثبتت:
G-1 مدخل `-i` واحد وتجاهل `assetId`، G-2 المسارات المتعددة تُلصق لا تُركَّب (مدة = المجموع)، G-3 الصوت المضاف يضيع، G-4 زوم/تحريك المقطع للعرض فقط.
لا يمكن إصلاحها بتعديل لصق التتابع؛ المركِّب جديد، **والمسار القديم باقٍ** لمشاريع المصدر الواحد البسيطة
(`needsCompositor()` يقرّر؛ لا فرق بصري بين المسارين لمشروع مسار واحد متتابع).

## نموذج التايملاين
| عنصر | القاعدة |
|---|---|
| مسار فيديو | مغناطيسي افتراضياً (ترصيف بلا فجوات). `magnetic:false` = تموضع حر بمواضع مطلقة |
| ترتيب التراكب | ترتيب المسارات في `project.tracks`: الأحدث/الأدنى في المصفوفة فوق |
| تداخل على مسار حر | **خطأ** `TRACK_OVERLAP` (لا يُحسم بصمت) |
| مسار مخفي `hidden` | لا يُرندر بصرياً (يبقى صوته إلا إذا كُتم `muted`) |
| مدة المخرَج | نهاية آخر طبقة مرئية؛ الصوت الأطول يُقتطع عندها. بلا فيديو: نهاية آخر صوت |
| دقة الزمن | كل `start/duration` تُقرَّب لشبكة إطارات المشروع (`snapToFrame`)، والمقطع ≥ إطار واحد |
| وسائط المصدر | `inPoint` + `duration×speed` يشتقان `trim` — المدة على التايملاين = المدة في المخرَج بالضبط |

## الخصائص المنفَّذة (كلها مغطاة باختبارات ffmpeg حقيقية في `render.integration.test.ts`)
**فيديو:** مصادر متعددة (ملفات بأبعاد/معدلات إطار مختلفة تُوحَّد)، صور ثابتة كطبقات، اقتصاص `crop`، تحجيم `scale` (صورة داخل صورة)،
موضع `posX/posY`، تدوير `rotation` (خلفية شفافة)، شفافية `opacity`، تلاشي `fadeIn/fadeOut`، سرعة 0.1×–8×، زوم/تحريك `zoom/panX/panY`،
مرشحات لونية جاهزة + تصحيح أساسي `color{brightness,contrast,saturation}`، 11 تأثيراً (`EFFECT_IDS`)، ترجمات ونصوص (ASS).
**انتقالات** (`transitionIn`: `dissolve`, `slide-left/right/up/down`): تنطبق على المقطع الداخل. إن كان قبله مقطع **متلاصق على المسار نفسه**
يُثبَّت آخر إطار له (`tpad clone`) مدة الانتقال ليبقى تحت المقطع الداخل. *لا* نستخدم لقطات «handles» من المصدر.
**صوت:** مصادر متعددة (صوت فيديو + ملفات مرفوعة)، مستوى `volume` (0–4)، `fadeIn/fadeOut`، إزاحة بدقة ميلي ثانية (`adelay`)،
`inPoint`، كتم المسار، **ducking** (الموسيقى/المؤثرات تنخفض تحت الفيديو/التعليق/الدبلجة عبر `sidechaincompress`، `amountDb` تقريبي)،
**تطبيع** جهارة (`loudnorm` هدف `targetLufs`، افتراضي −16).
**تصدير:** إعدادات مسبقة (`export-presets.ts`)، دقة/معدل إطار، تقدّم، إلغاء (يقتل ffmpeg ويحذف الجزئي)، مهلة، تنظيف ملف ASS المؤقت في `finally`.

## الأخطاء والاسترجاع
- أصل مفقود/غير قابل للقراءة ⇒ `SOURCE_MISSING` (HTTP: المهمة تفشل برسالة + `issues[]`؛ MCP: `NOT_FOUND` فورياً). لا إسقاط صامت.
- صوت لا ملف له على الخادم (blob المتصفح) ⇒ `AUDIO_SOURCE_MISSING` خطأ، إلا بإقرار `acknowledgeAudioLoss` فيصير تحذيراً. الحل: `/api/assets/upload`.
- فشل/إلغاء/مهلة ⇒ حذف المخرَج الجزئي؛ `completed` فقط بعد مراجعة `reviewRender`.
- المهام في ذاكرة العملية (D-02 في التدقيق) — لا استئناف بعد إعادة تشغيل الخادم؛ المهمة تُعلَّم فاشلة.

## تطابق المعاينة والتصدير — التفاوتات الموثّقة
| ما يُقارَن | التفاوت المضمون | الدليل |
|---|---|---|
| معاينة MCP (نافذة + دقة منخفضة) ↔ التصدير الكامل | **نفس الخطة**: المحتوى/المواضع/التوقيت متطابقة؛ دقة البكسل تختلف بالحجم والضغط | اختبار `consistency` |
| المدة | ±3 إطارات (±0.1s) | اختبارات المدة |
| مزامنة الصوت | ≤10ms نظرياً (`adelay`)؛ التحقق بنوافذ 0.1–0.3s | اختبار fade/sync |
| لون المرشحات | تقريب `eq` لمرشحات CSS — **ليس** مطابقاً بكسلياً | ملاحظة `COLOR_FILTER_FFMPEG` |
| معاينة المتصفح (CSS/video) ↔ التصدير | **غير مضمونة بكسلياً**: المتصفح لا يطبّق `transitionIn`، ducking، تطبيع، ولا يركّب الصورة ضمن مسارات متعددة بدقة ffmpeg. المرجع الحاكم = المعاينة المرندرة (`generate_preview`/زر «معاينة مرندرة») | انظر «غير مدعوم» |

## غير مدعوم عمداً (موثّق لا مُحاكى)
- **مفاتيح (keyframes)** للخصائص عبر الزمن: غير منفَّذة؛ القيم ثابتة لكل مقطع. (زوم smart-zoom يُستخدم كقيمة ثابتة.)
- **انتقالات بلقطات handles** حقيقية من المصدر؛ المنفَّذ تجميد آخر إطار (انظر أعلاه). انتقالات أخرى (wipe/iris/…) غير موجودة.
- **mask/chroma-key/blend modes/تتبع حركة/استقرار متعدد الطبقات**: غير موجودة. `videoStabilize` عام وأحادي الممر على المخرَج.
- **خط ألوان احترافي** (LUT/منحنيات/عجلات): غير موجود؛ تصحيح أساسي فقط.
- **تدوير/اقتصاص للصور المتحركة داخل المعاينة المرندرة بخطوط نصية مخصصة**: النص عبر ASS بخط واحد افتراضي (Arial) — لا اختيار خطوط.
- **صيغ احترافية** (ProRes/DNxHD/صوت متعدد القنوات 5.1): غير مدعومة؛ الصيغ: mp4/mov/mkv (H.264+AAC)، webm (VP9+Opus).
- **تغيّر السرعة المتغيّر (ramping)** وعكس الفيديو: غير موجودان.
- **استئناف الرندر بعد انهيار الخادم** وتخزين دائم للمهام: غير موجود.
- **عدّاد تغيير معدل العينة/القنوات للصوت الأحادي المتعدد**: كل الصوت يُحوَّل إلى ستيريو 48kHz.
