## المهام المتبقية (بهذا الترتيب، كل واحدة بالتزامات صغيرة واختبارات)

### 1) T-18/T-19: تخزين دائم (SQLite) وعامل تصدير
- المشكلة: مهام التصدير في ذاكرة العملية (`aiJobs` في `lib/mockAi.ts`) وملفات JSON بلا قفل متعدد العمليات (`lib/engine/store.ts`)؛ إعادة تشغيل الخادم تُفقد المهام الجارية.
- المطلوب: طبقة تخزين للمهام (والمشاريع إن أمكن) فوق SQLite (`better-sqlite3` أو `node:sqlite`) مع قفل كتابة؛ عامل تصدير في عملية منفصلة (`child_process.fork`) كي لا يجمّد الخادم؛ إعادة التشغيل تُعلّم المهمة الجارية «فاشلة: انقطعت» بدل أن تضيع.
- قبول: اختبار يقتل العامل أثناء التصدير ويثبت الحالة بعد إعادة التشغيل؛ اختبار ترحيل من تنسيق JSON الحالي دون فقد بيانات؛ المحرّر وMCP يمرّان بالطبقة نفسها (مبدأ «مصدر واحد» في CLAUDE.md). الترحيل قابل للتراجع.

### 2) T-09: عزل FFmpeg
- المطلوب: تشغيل ffmpeg/ffprobe داخل `bwrap` (أو `unshare`) مع `--unshare-net` وقراءة مجلد الوسائط فقط، كخيار `MONTAGE_FFMPEG_SANDBOX=auto|bwrap|off`، يتدهور بأناقة إن غابت الأداة.
- قبول: اختبار حقيقي يثبت أن العملية المعزولة لا تصل شبكة ولا تقرأ خارج المسموح. **إن لم تتوفر `bwrap` أو user namespaces في البيئة فلا تدّعِ النجاح**: اكتب الشيفرة والاختبار بحيث يُتخطّى بوضوح (skipped لا passed) وصرّح بذلك.

### 3) المرحلة 7: الوكلاء والذكاء
- توحيد منطق CEO: `app/api/agents/ceo/route.ts` (TS، ~640 سطراً) مقابل `src/agents/ceo_agent.py`. اجعل Python المرجع والمسار TS غلافاً رفيعاً عبر الجسر القائم؛ لا تكسر عقد EDL (`node scripts/check-contract.ts`).
- تفريغ صوتي محلي اختياري (faster-whisper) يستبدل المحاكاة عند توفر الحزمة، وتدهور أنيق بدونها.
- حوّل أكثر مهارات `simulated` استخداماً (Silence/Scene/Highlight) إلى تحليل حقيقي عبر `lib/engine/media.ts` مع `provenance=real-analysis`.
- لا نتائج مُختلقة: كل بديل تقديري يُوسم `simulated:true` + تحذير.

### 4) المرحلة 8: جودة وصيانة
- تفكيك `components/editor/Editor.tsx` (~3500 سطر) تدريجياً إلى hooks/مكوّنات تحت حماية `pnpm ui:smoke` و`scripts/e2e-ui.mjs`؛ التزام صغير لكل استخراج.
- `lib/mockAi.ts`: افصل ما هو حيّ (`aiJobs`, `EFFECTS_LIBRARY`, `generateToneTrack`) عن المحاكاة القديمة واحذف غير المستدعى بعد `grep`.
- غلاف `withRoute()` موحّد (أخطاء + سجلات `logger` + مصادقة)، وإنهاء استبدال `console.*` في المسارات.
- رفع مجزّأ (TUS) لملفات GB: `req.formData()` يحمّل الجسم في الذاكرة حالياً.
- CSP بـ nonce لإزالة `unsafe-inline` (يتطلب middleware لكل صفحة؛ اختبر كل الصفحات بصرياً).

### 5) تحقق بصري لم يُنجز بعد
- معاينة التأطير الذكي (`lib/engine/framing.ts` ← تحويل CSS على `<video>`) لم تُشاهد في متصفح: أضف مدخلاً لاستيراد مشروع بمقطع `smartZoom` (أو إعداداً في الاختبار) وتحقق بـ Playwright.
- نافذة تأكيد فقدان الصوت وتدفق رفع الصوت التلقائي من الواجهة.

## قيود لا تُنتهك
- لا إعادة بناء من الصفر ولا حذف ميزة تعمل. لا تُضعف أي حماية أمنية لتمرير اختبار؛ عدّل الاختبار فقط إن كان يفترض سلوكاً أضعف (كما حدث مع مصافحة الموافقة).
- كل جسم JSON خارجي عبر `parseJsonBody` + مخطط. لا `req.json()` خام. لا مسارات قرص في أي استجابة. لا `shell:true`. تشغيل ffmpeg/python عبر `hardening.ts`.
- مسارات `route.ts` في Next 15: لا تُصدّر دوال غير معيارية منها (ضعها في `lib/`)، و`params` غير متزامنة، و`dynamic(...,{ssr:false})` تحتاج مكوّناً عميلاً. **شغّل `pnpm build` قبل أي دمج** (اكتشف أخطاء لا يكتشفها `tsc`).
- التزامات بالعربية، **بلا أي معرّف نموذج** (Sonnet/Opus/gpt...) في الالتزامات أو الكود أو PR.
- لا تُعلن نجاحاً دون دليل. كل بند ينتهي بـ: ما شغّلتَه، نتيجته، وما لم تختبره.

## الفحوص قبل كل التزام (كلها يجب أن تنجح)
```
npx tsc --noEmit && pnpm lint && pnpm test && node scripts/check-contract.ts \
  && python -m pytest && pnpm mcp:e2e && pnpm build && pnpm audit --prod
# للتغييرات التي تمس الواجهة أو التصدير: شغّل خادماً (pnpm start) ثم
BASE_URL=http://localhost:3000 pnpm ui:smoke
```
تنبيه: لا تسلسل الأوامر بـ `;` ثم تلتزم؛ اجعل الفشل يوقف السلسلة (`&&`).

## الدمج
اعمل على فرع الجلسة المخصّص، ادفعه، افتح PR بجسم يبيّن: الملخص، الاختبارات التي شُغّلت، وما لم يُتحقق منه. تحقق من نتيجة CI على GitHub (`actions_list`) قبل الدمج إن كان متاحاً. بعد الدمج أعد بناء الفرع من `main` الأحدث. **حذف الفروع محجوب من الجلسات السحابية** (الخادم الوسيط يقطع `git push --delete` ومصنّف الصلاحيات يرفض `gh api`): اتركه للمالك وأبلغه بالفروع المدموجة. تنبيه: قد تعمل جلسة موازية على `main`؛ اجلب `origin/main` قبل الدفع وحلّ التعارضات بحذر (جانب `main` الأحدث ما لم يكن في جانبك إصلاح أمني).
