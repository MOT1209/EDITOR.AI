1. إزالة الصمت أصبحت تقص الفيديو فعلياً مُصلح ✓

أُعيد بناء منطق aiSilenceRemove: بدلاً من إضافة مقاطع صمت معلّمة _removed لا يقرأها أحد، أصبح الآن يفلتر المقاطع المحتفظ بها فقط (المقاطع غير الصامتة بعد القص) ويُسقط فترات الصمت من التايملاين بالكامل — فعند التصدير يُنتج الفيديو النهائي بدون توقفات صامتة.

🔧 التنفيذ: إعادة كتابة aiSilenceRemove في Editor.tsx — قص segments الواردة من /api/ai/silence إلى فترات "محتفظ بها" بدل فترات "محذوفة"، مع التحقق من النطاقات وتجاهل الفراغات.

2. التثبيت وتصحيح الألوان يصلان الآن للتصدير FFmpeg مُصلح ✓

قيمتا videoStabilize وcolorGrading كانتا تؤثران على المعاينة فقط. الآن تُمرَّران في طلب /api/export وتتحولان إلى فلاتر FFmpeg حقيقية تُطبَّق على الفيديو النهائي.

🔧 التنفيذ: في lib/server/ffmpeg-export.ts أُضيف فلتر deshake=rx=16:ry=16:edge=mirror عند تفعيل التثبيت (حافة مرآتية بلا أشرطة سوداء)، وفلتر eq للتصحيح اللوني عبر colorGradingFilter() — وهو يربط القوة الرقمية (0..1) بالفلتر بنفس صيغة المعاينة CSS، ويعيد null عند القيمة المحايدة 0.5 فيُتخطى الفلتر تماماً. ويُرسل كليهما من startExport في المحرر.

3. الدبلجة عبر مسار TTS حقيقي (بدل الصوت الفارغ) مُصلح ✓

زر "الدبلجة بصوت مستنسخ" كان يُنشئ مساراً بـ url: "". الآن يوجد مسار app/api/ai/tts/route.ts يستدعي خدمة TTS (OpenAI-compatible عبر /audio/speech) مع خريطة أصوات عربية وإنجليزية، ويعيد الصوت كـ Base64 يحوّله المحرر إلى Blob URL حقيقي يُضاف للتايملاين.

🔧 التنفيذ: مسار tts جديد + إعادة كتابة aiDub ليحول audioBase64 → Blob → URL.createObjectURL، مع رسالة واضحة عند غياب مفتاح API بدل الصمت.

4. موسيقى حقيقية مولّدة عبر Web Audio API + مشغّل صوت مُصلح ✓

مكتبة الموسيقى كانت بلا ملفات (url: ""). الآن الدالة generateToneTrack في lib/mockAi.ts تولّد نغمة موسيقية حقيقية (Web Audio + MediaRecorder) حسب BPM ومزاج المسار، تُسجَّل كـ Blob URL. كما أُضيف عنصر <audio> فعلي في المعاينة — كان الصوت يُضبط كحالة لكن لا يُشغَّل إطلاقاً.

🔧 التنفيذ: generateToneTrack (تتابعات كوردات حسب المزاج، حلقة 8 ثوانٍ) + مشغّل <audio loop autoPlay> مرتبط بـ audio.url في المعاينة، وربط aiFullAuto بالموسيقى المولّدة. وتُعالج سياسة المتصفح عبر ctx.resume() عند إنشاء السياق الصوتي، مع إغلاقه (ctx.close()) بعد التسجيل لمنع تسريب الموارد.

5. زر Shorts يستدعي ShortsGenerationSkill الحقيقي مُصلح ✓

كان aiShorts شريط تقدم فقط. الآن يستدعي نظام الـ Skills عبر /api/skills بوضع skill: "ShortsGenerationSkill" مع بيانات المدة ونسبة العرض، ويحوّل مقاطع shorts المرتجعة إلى قصاصات حقيقية على التايملاين بعدد يطابق اختيار المستخدم.

🔧 التنفيذ: إعادة كتابة aiShorts للاستدعاء الفعلي للـ Skill وتحويل النتيجة (start/end/score) إلى مقاطع تُضاف للمشروع — وإن لم يعثر التحليل على لحظات مميزة، يُظهر إشعاراً واضحاً قبل الرجوع للقص المتساوي (لا fallback صامت).
