# MontageAI 🎬

**محرر فيديو بالذكاء الاصطناعي — تشغيل ذاتي على جهازك، بلا حساب ولا اشتراك في المنتج**

تطبيق مونتاج فيديو يحرّر الفيديو تلقائياً. تشغّله محلياً على جهازك (Next.js + FFmpeg)،
والمشاريع تُحفظ في متصفحك (`localStorage`) — لا حساب، لا اشتراك، لا خادم تابع لنا.

> **ملاحظة مهمة عن الخصوصية:** ميزات المونتاج الأساسية (القص، إزالة الصمت، الألوان،
> التصدير، الموسيقى) تعمل **محلياً بالكامل** عبر FFmpeg. أمّا ميزات الذكاء الاصطناعي
> التوليدي (تفريغ الصوت، الترجمة، الدبلجة، تحليل المشاهد/الوجوه بالرؤية، توليد
> العناوين) فتُرسل البيانات المطلوبة (الصوت المستخرج، النص، إطارات مختارة) إلى
> **مزوّد LLM خارجي** تختاره أنت وتضبط مفتاحه (Groq / OpenAI / Gemini / Hugging Face
> / Pexels). بدون مفتاح: هذه الميزات تُعطى بيانات معاينة أو تُعطَّل — والمسار لا ينهار.

## 🔒 ما يعمل محلياً مقابل ما يحتاج مفتاحاً سحابياً

### يعمل محلياً بالكامل (FFmpeg / حسابات على الجهاز — لا يغادر شيء)

| الميزة | الآلية |
|--------|--------|
| **إزالة الصمت** | `ffmpeg silencedetect` — كشف وحذف التوقفات |
| **القص والترتيب التلقائي** | خطة قواعد محلية (EDL) على أساس الصمت/الحركة |
| **كشف السكون والسواد** | `auto-editor` (اختياري) أو `freezedetect`/`blackdetect` |
| **تحسين الصوت** | فلاتر `afftdn` + `loudnorm` |
| **تحسين الألوان / الفلاتر** | فلاتر `eq`/`hue`/`gblur` |
| **تثبيت الفيديو** | `ffmpeg deshake` |
| **موسيقى الخلفية** | مكتبة مقاطع محلية + توليد نغمات عبر Web Audio API |
| **مزامنة القص مع الإيقاع** | حساب BPM/الضربات رياضياً |
| **Thumbnail** | تركيب نصّي عبر SVG/Canvas محلياً |
| **التصدير والرندر** | `ffmpeg libx264/NVENC` — تنفيذ كامل على الجهاز |
| **تصدير NLE** (Premiere/Resolve/Shotcut/Kdenlive/FCP) | `src/export_nle.py` |
| **حفظ المشاريع** | `localStorage` في المتصفح |

### يحتاج مفتاح مزوّد — تُرسَل بيانات إلى خدمة خارجية

| الميزة | ما يُرسَل | المزوّد / المتغيّر |
|--------|-----------|--------------------|
| **تفريغ الصوت (Whisper)** | ملف الصوت المستخرج (mp3 16kHz) | `OPENCODE_API_KEY` + `WHISPER_MODEL` |
| **الترجمة إلى لغات أخرى** | نص الترجمة | `OPENCODE_API_KEY` أو `HF_TOKEN` |
| **الدبلجة / تحويل النص لصوت (TTS)** | النص المراد نطقه | `OPENCODE_API_KEY` |
| **تحليل المشاهد / إعادة التأطير بالرؤية** | إطارات مختارة (صور) | `OPENCODE_API_KEY` (+ `OPENCODE_VISION_MODEL`) |
| **كشف الوجوه / الأجسام (سحابي)** | إطارات مختارة (صور) | `HF_TOKEN` |
| **توليد العناوين / الأوصاف / الهاشتاغ** | نص الترجمة | `OPENCODE_API_KEY` |
| **الخطة الإبداعية للمونتاج (Director LLM)** | تقرير التحليل + التفريغ | `OPENCODE_API_KEY` |
| **B-Roll** | نص الكلمات المفتاحية فقط | `PEXELS_API_KEY` |

> كشف الوجوه وتتبّعها يمكن أن يعمل **محلياً** أيضاً عبر OpenCV إذا ثبّتّ الحزم
> الاختيارية (انظر «الميزات المحلية الإضافية» أدناه) — عندها لا يُرسَل شيء.

## 🖥️ التقنيات

- **Next.js 14** — إطار العمل (App Router + TypeScript)
- **TailwindCSS** — التصميم والتنسيق
- **FFmpeg** — معالجة الفيديو والصوت محلياً (إلزامي)
- **Web Audio API** — توليد الموسيقى والنغمات محلياً
- **LocalStorage** — حفظ المشاريع في المتصفح
- **مسار وكلاء Python** (`src/agents/`) — CEO → Analyst → Director → Critic → Audio → Render
- **مزوّد LLM متوافق مع OpenAI** (اختياري) — لميزات الذكاء التوليدي فقط

## 🚀 التشغيل

> **نموذج التشغيل:** تطبيق **محلي / تشغيل ذاتي**. مسار المونتاج الكامل ينفّذ رندر
> FFmpeg عبر عملية فرعية داخل خادم Next (`maxDuration` حتى 300 ثانية)، لذا **لا يصلح
> للنشر على بيئات serverless** (مثل Vercel) — شغّله على جهازك أو خادم كامل.

```bash
# 1) تثبيت حزم الواجهة
pnpm install                    # (أو npm install)

# 2) (اختياري) تثبيت مسار وكلاء Python
pip install -r src/requirements.txt

# 3) ضبط المفاتيح (اختياري — لميزات الذكاء الاصطناعي)
cp .env.example .env.local      # ثم املأ OPENCODE_API_KEY وغيره

# 4) تشغيل خادم التطوير
pnpm dev
```

ثم افتح [http://localhost:3000](http://localhost:3000)

- **إلزامي:** تثبيت **FFmpeg** على الجهاز (أو ضبط `FFMPEG_PATH`).
- **بلا مفاتيح:** كل الميزات المحلية تعمل؛ ميزات الذكاء تعطي معاينة أو تُعطَّل بلطف.
- يمكن إدخال المفتاح أيضاً من نافذة **«إعدادات API»** داخل التطبيق (يُخزَّن في متصفحك
  ويُمرَّر كترويسة للطلب — لا يُحفَظ على الخادم).

### الميزات المحلية الإضافية (تثبيت اختياري)

```bash
pip install faster-whisper opencv-python-headless   # تفريغ صوتي محلي + كشف وجوه محلي
python scripts/install-auto-editor.py               # ثنائية auto-editor (~44MB)
```

│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx

├── lib/
│   ├── skills/           # نظام المهارات: BaseSkill + الكتالوج + SkillManager + Workflow
│   ├── captions/         # قوالب وتصدير الترجمات
│   ├── server/           # مفاتيح API + تصدير FFmpeg + الأصول
│   ├── agents/types.ts   # عقد EDL بلغة TypeScript (مطابق لـ Python)
│   ├── project.ts        # إدارة المشاريع (حفظ محلي)
